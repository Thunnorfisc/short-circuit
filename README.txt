Controls:

1. World Map
	- Blue outlined node is where you are currently
	- Hover over any node to see their type of node
	- Click on the node in the next bound that is connected with a blue line to your node to enter the event

2. Battle System
	- Drag circuit pieces from the bottom list to the tile you want to place it at
	- Once the circuit is closed in a loop or there is no way to close, click the cast button to cast an attack
	- If the circuit is open when casted, no damage will be done to the enemy

3. Item and Shop Events
	- Hover over any items to see what it does
	- Click on the item you want to obtain
	- In shop, if it is unaffordable, currency amount will be red and cannot be bought
	- Shop is skippable with the "SKIP >>" button
